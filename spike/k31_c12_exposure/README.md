# Bounded C12 exposure

This spike uses current production serving and result interfaces. Its scripts do not land.
The committed protocol fixes the full model position limit, the current C12 capacity,
K3/AL2.88, the short client windows and independent outer failure bounds.
Planning launches no model or client and does not grant GPU access.

The initial plan is available for review while the public profiler/export qualification,
canonical bundle production and runtime/cache receipts are completed. GPU execution remains
disabled until an exact committed driver and its complete readiness evidence are reviewed.
