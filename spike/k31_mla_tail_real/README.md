# One actual native MLA-tail invocation

This preparation preserves the retired fixture experiment's inconclusive result.
It cannot change old bounds or certify a model/C12 benefit. The initial inventory found historical rank0 data, synthetic frontend controls
and CPU K2 fixtures, without the required complete current all-rank tuple.

The prospective treatment is current Mono1, TP8/DCP8, K3/AL2.88 with the bound
current precision/state recipe. One fixed real request selects DSA layer3 and
request bucket(1,4). An ordinary live replay is witnessed first; only the next
matching invocation uses the named capture graph. Missing exposure, unsupported
layout/precision or mismatched rank identity stops without a search or retry.

The capture records raw partial output, FP32 LSE, owned counts, BF16 W_V_dcp,
gate, gated reference, input IDs/positions, strides/aliases, native mailbox
capacity/tile and the actual captured decode route. Raw tensors are not retained
past their native call; only scalar layout descriptions cross the tap stages.
One-shot copy buffers have separate ownership. Two tiny pre-replay D2H identity
copies and snapshot copy/storage costs are explicit capture overhead, not timing.
Temporal gate/input aliases are unsupported rather than silently repacked.

Generic range/hash/restore/copy machinery and pinned routing bodies are rebound
in a task-local process. K2 schemas, layer17 payloads and historical shape
qualifications are excluded. Canonical helper globals preclude an implicit joint
capture. The other task never waits for this work; sharing needs a separate,
explicitly compatible reviewed plan. No current shared-load plan exists.

Normal replay admission requires the complete matched eight-rank manifest and successful producer
cleanup. Both arms consume the same actual tuple; external o_proj and gate
production are excluded equally, with no scheduling benefit claimed. Original
stage strides and aliases remain represented; unsupported inputs are rejected.
Input materialization bytes and GPU span are reported separately. No weight/gate
repack is free. Native mailbox clear/epoch work remains inside its kernel.

Before any new observation the protocol is fixed: one warmed immutable input set,
128 calls per graph, five alternating A/A pairs then five AB/BA pairs, maximum
rank GPU-event time and per-pair rank skew. Reference and derived empty/invalid-LSE
controls retain finite output, global-relative<=2^-7, BF16 equality>=99.9% and
exact empty zero; derived controls are not representative inputs. Any A/A paired
ratio beyond2% makes timing inconclusive. Otherwise all AB ratios>1.02 advance,
all<0.98 reject, and mixed/near-noise results are inconclusive. Author observed
per-arm min/max intervals are frozen before independent reproduction; its
five-sample medians must lie inside without widening. Failure never auto-retries.

900 and180 seconds, including result validation in an owned CPU child under the

unblocked child stop signals,
